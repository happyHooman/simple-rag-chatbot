  → All should be "Up" and "healthy"

401 Unauthorized in Swagger?
  → Click "Authorize" first
  → Enter: test_token

Flower not loading?
  → Wait 15 seconds (dev dependencies installing)
  → Check: docker compose logs flower

Adminer connection failed?
  → Server must be: postgres (not localhost)
  → Check postgres is healthy: docker compose ps

No embeddings in database?
  → Run /generate-embeddings endpoint first
  → Check task succeeded in /tasks/{task_id}
