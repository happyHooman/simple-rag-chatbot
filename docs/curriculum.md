# Curriculum

The playground is organised into six tracks. Each track is a sequence of labs
under `labs/<track>/`.

1. **Foundations** - tokens, prompting, structured output, embeddings, calling LLM APIs.
2. **RAG** - chunking, embeddings and similarity, vector stores, hybrid search, reranking.
   - [Lab 01: Embeddings & similarity](../labs/rag/01-embeddings-similarity/) (FAQ chatbot)
3. **Agent patterns** - tool use, ReAct, plan-and-execute, reflection, memory.
4. **Multi-agent** - supervisor/worker, hierarchical, debate, swarm/handoff architectures.
5. **Evals and observability** - eval datasets, LLM-as-judge, tracing, cost and latency.
6. **Ops** - containers, Terraform, Kubernetes, CI/CD, serving and scaling LLM apps.
